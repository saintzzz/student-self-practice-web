# Edu-App Research - 2026-W46 (UI/UX edition)

Companion to `2026-W46.md` (pedagogy). This pass surveys the INTERFACE
patterns of the highest-retention K-5 apps and diffs them against the
English Arena exam experience.

## Landscape findings

| Pattern | Best example | What they do | Our status |
|---|---|---|---|
| Character reacts to every answer | Duolingo (Duo), Khan Kids (Kodi) | Mascot celebrates correct, encourages on wrong - the character IS the feedback channel | MascotArt already has celebrating/encouraging poses + CSS mood motion; exam verdict does not use it |
| Combo/streak-in-session | Duolingo (combo counter), Prodigy | Consecutive-correct counter visible during the sitting, burst at milestones | None - verdict is per-question only |
| Confetti on correct | Khan Kids, ST Math (JiJi jumps) | Small burst animation at the moment of correctness, <400ms | Keyframes exist (mascot-pop, streak-burst); verdict block renders statically |
| Big tappable options | All K-5 leaders | Options = huge cards/images, not radio rows | Option buttons already large; puzzle images now full-size (r187 fix) |
| Wrong = safe | Duolingo, ST Math | No red alarm, friendly "try again" framing + character encouragement | Verdict says "Chưa đúng rồi." - ok copy, but no character softness |

## Gap analysis

The design system is already strong (tokens, press-spring, motion-reduce
discipline, mascot pose set, per-mood CSS motion). The missing layer is
**reactive**: the character and micro-celebration exist as assets but are
not wired to the answer moment. This is exactly the cheapest-highest-delight
gap - no new art needed, just wiring.

## Decisions (PO)

1. **IMPLEMENT - mascot verdict reaction** (this cycle): practice verdict
   shows `Mascot` with mood `celebrating` on correct / `encouraging` on
   wrong, companion size, inside the verdict block. Uses existing art +
   motion; zero new assets.
2. **IMPLEMENT - session combo counter** (this cycle): consecutive-correct
   count in the verdict block - "x3 liên tiếp!" appears at >=3 with the
   existing `mascot-pop` animation. Duolingo's combo mechanic, kid-safe
   (no loss framing, counter resets silently).
3. **BACKLOG** - result-screen celebration pass (confetti burst on result
   reveal), correct-answer star-fly to progress ring (keyframes exist).
4. **NO** - do not copy Duolingo hearts/lives (punitive) or Prodigy
   pay-to-win loops; both conflict with the pedagogy-first position.

## Rule reaffirmed

Assets: reuse existing pose art + keyframes only. No new art pipeline
work inside a research cycle - new art needs its own CR.
